## Análise do Brilho Estelar

Trabalho da pós-graduação em Ciência de Dados.

## Objetivo
Simular e analisar dados de brilho estelar utilizando distribuição normal.

## Ferramentas
- R
- ggplot2
- Google Coolab

## Autor
Gabriel de Oliveira Marques

## Professores
Sérgio Monteiro, D.Sc.
Manuel Martins, D.Sc.

## Objetivos
-  Simular dados de brilho estelar
-  Avaliar a aderência à distribuição normal
-  Estimar parâmetros populacionais
-  Identificar outliers e seu impacto

## Principais análises
-  Histograma com curva normal
-  Intervalo de confiança (95%)
-  Teste de hipótese (t-test)
-  Detecção de outliers (IQR)

## Conclusão
A simulação das medições de brilho estelar apresentou comportamento consistente com uma distribuição normal, conforme evidenciado tanto pela análise visual 
quanto pelos resultados estatísticos obtidos. O intervalo de confiança de 95% incluiu o valor teórico esperado (μ = 15.5), reforçando a confiabilidade das 
medições simuladas, enquanto o teste de hipótese não indicou diferença estatisticamente significativa entre a média amostral e esse valor, sugerindo que os 
dados estão devidamente calibrados. Além disso, a análise de outliers identificou apenas poucas observações extremas, cujo impacto na estimativa final foi mínimo, 
indicando, de forma geral, uma boa qualidade dos dados.
